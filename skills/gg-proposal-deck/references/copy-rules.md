# 版面・文言・数字の規約（copy-rules.md）

> **状態：`SKILL.md` の品質チェックリストから規約化したもの。判定基準としてそのまま使える。**
> 具体的な版面数値（フォント・級数・余白）は正本が手元にないため未記入。
> `scripts/build_deck.js` が実装している値を暫定としている。

## 文言

| ルール | 判定 |
|---|---|
| リード文はすべて「です・ます」 | 例外なし |
| 先方の言葉を勝手に言い換えない | ヒアリングで出た語をそのまま使う |
| 仮案・仮設定には「仮」と明記する | 明記のないものは確定とみなされる |

## 数字

| ルール | 判定 |
|---|---|
| すべての数字に**出所と調査時点**がある | `source` が空のまま数字を載せない |
| 効果予測は**レンジ**で書く | 単一値の断定を置かない |
| 未確認の数値を「実績」と書かない | 推定には必ず「推定」と明記（`AGENTS.md` 第3章6） |

## 版面

| ルール | 実装 |
|---|---|
| 全ページにフッター `NN\|総ページ数` | `build_deck.js` が自動付与。手で書かない |
| 章扉は 通番／英ラベル／日本語章名 の3点セット | 欠けると生成が落ちる |
| 別紙への参照を明記する | デザイン・WF・仕様書。本文に書く |

### 暫定の版面値（`build_deck.js` の実装値）

| 項目 | 値 |
|---|---|
| 比率 | 16:9（10 × 5.625 インチ） |
| 余白 | 上下左右 0.55 インチ |
| フォント | Meiryo |
| タイトル | 20pt / 太字 |
| リード文 | 12pt |
| 本文・表 | 11〜13pt |
| フッター・出典 | 9pt |

正本の値が判明したら、この表と `build_deck.js` の `COLOR` ・ `FONT` ・ サイズ定数を同時に直す。
