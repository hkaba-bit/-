### [2026-09-18] 仕様書サイトマップ（Excel）の初版 — Claude
- 成果物:
  - `projects/johoku-saitama/spec/sitemap_spec.json`（JSON定義。正本）
  - `projects/johoku-saitama/spec/仕様書_城北埼玉中学高等学校_提案サイトマップ.xlsx`（生成物）
  - `scripts/recalc-countif-fallback.py`（環境都合の追加。下記）
- 検証:
  - `skills/gg-sitemap-spec/scripts/verify_sitemap_xlsx.py` → **FAIL 0 / WARN 1** ＝ OK
  - WARN の内容：「第1階層が8項目」。**意図どおり**。グローバルナビに載る第1階層は
    学校案内／教育・コース／学校生活／部活動／入試・説明会／お知らせ の**6項目**で、
    WARN が数えている8項目には `TOP` と `共通・その他`（サイトマップ・規約類・据え置きページ）が
    含まれている。スキルの WARN 文面が指示する「TOP・詳細ページ・CV導線・規約類を除いた数え方」で6項目。
  - 集計行（COUNTIF）のキャッシュ値：構成 1/1/11/4、デザイン 1/1/10/10、コーディング 1/1/10/13/16/0。
    受注条件との対応を下記のとおり確認。
- 判断メモ:
  - **受注条件との対応**（ズレなし）
    | 受注条件 | シート上の定義 | 実測 |
    |---|---|---|
    | 設計16P | 構成列に■が1つ以上ある行数 | **16行** |
    | デザイン11P | デザイン列に■が1つ以上ある行数＝テンプレート数（TOP1＋フォーマット10） | **11行** |
    | 流し込み2,365P | ID19 `/news/{slug}` の移行件数（行数ではなく数量） | 2,365 または 2,321（**要確認**） |
    | WordPress | コーディングWP列 | 16行（更新性◎7行＋○7行＋自動生成2行） |
    設計16 − デザイン11 ＝ 5行が「構成は起こすがデザインは既存テンプレートを流用する」ページ
    （`/info/philosophy/` `/access/` `/course/` `/course/regular/` `/course/frontier/`）。
    枠内に収めるため、この5行はデザイン列を空にしてある。
  - **枠を超えないための判断**：説明会詳細 `/admission/briefings/{slug}` は
    `/news/{slug}` の記事型を流用し、開催日・会場・申込URLをカスタムフィールドで足す扱いにした。
    独立したテンプレートにするとデザインが12Pになるため。
  - **施設案内**は独立ページを立てず `/school-life/` に統合した。同じ理由（16Pに収める）。
  - **論理構造の出発点**は現行の実URL体系。URLを据え置いたのは `/info/` `/access/` `/club/` `/news/` `/sitemap/`
    （1997年取得ドメインの評価を落とさないため、清書できるものはそのまま使う）。
    `/junior-high-school` `/hs-regular-course` `/hs-frontier-course` は `/course/*` へ再編（命名の不統一の解消）。
  - **更新性**は brief 論点03 に合わせ、入試情報◎・お知らせ◎・部活動（詳細）◎／（一覧）○。
    判定根拠は全行の備考欄に記載（例：部活動一覧は「部の新設・統廃合が年数回」で○）。
  - **数値は創作していない**。記事数は 2,365 と 2,321 を**両方併記**し「要確認」と明記。
    GA4実数は未取得のため、シートに数値目標・セッション数の類は一切入れていない。
  - **URL移行ブロック**に旧→新の対応表と301の総件数の考え方を記載。
    `--><!--` を含む**不正URL約90本は移行対象に含めない**旨を「制作対象外」と「URL移行」の両方に明記した
    （`current-site-audit.md` P0。実体ページではなくテンプレートのコメント崩れによる生成物のため）。
  - **フォーム列は合計0件**。資料請求・お問い合わせフォームが受注条件に含まれていないため、
    行を勝手に足さず「制作対象外」＋「要確認事項3」に上げた。
  - **環境都合**：この実行環境（Claude Code on the web）の LibreOffice は xlsx を読み込めず
    （`soffice --convert-to` が "source file could not be loaded"、最小の xlsx でも再現）、
    `xlsx` Skill の `recalc.py` が 400秒でもタイムアウトする。集計行が COUNTIF のみなので、
    値を計算して sheet XML に差し込む `scripts/recalc-countif-fallback.py` を追加して代替した。
    **LibreOffice が動く環境では従来どおり `recalc.py` を使う。**
